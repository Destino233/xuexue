# v0.1 alpha acceptance scope

This release is a usable vertical slice of the design documented in
[`ARCHITECTURE.md`](ARCHITECTURE.md). The Gradle project version is
`0.1.0-alpha`; Deb and MSI package metadata uses `0.1.0`. The DMG metadata uses
the minimum Apple-compatible version `1` because Apple requires a positive
major number. It does not represent a 1.0 product release.

## Required flows

1. First launch offers create/open workspace and does not create a blank note.
2. A workspace exposes the real directory tree and can open Markdown, text,
   image, and PDF documents in preview or pinned tabs.
3. Markdown supports structured editing, source editing, reading, formatting,
   completion, and atomic autosave.
4. Search, outline, outgoing wiki links, tags, backlinks, properties, and the
   local graph navigate to files.
5. PDFs use MuPDF viewport tiles and support continuous/single/double-page
   modes, fit modes, smooth anchored zoom, rotation, night reading, search,
   native text selection and links, independent overlays, annotations,
   reference-note creation, persisted reading offsets, cancellation, and
   progressive HTTP Range loading through a backend interface.
6. Agent chat uses DeepSeek Harness and supports document, file, and snippet
   context, tool approvals, multiple sessions, and cancellation.
7. Docking, split documents, detached windows, named layouts, compact
   navigation, and panel sizes persist across restarts.
8. File watching, transactional batch rename, wiki-link rewriting, trash/undo,
   and external-change recovery are available.

## Storage contract

- Workspace files remain the source of truth for notes and imported documents.
- `.xuexue/workbench.properties` stores rebuildable layout and navigation state.
- `.xuexue/dsh-transcripts.jsonl` in the workspace stores displayed messages and
  DSH session IDs. DSH stores resumable model context under its own home,
  `~/.xuexue/dsh` by default. Earlier `agent-sessions.jsonl` and JSON transcripts
  can be opened as archives.
- `.xuexue/pdf-annotations.json` stores PDF annotations and is not
  reconstructable from the source PDF.
- `.xuexue/trash/` and rename staging directories support recoverable file
  operations and must not be indexed as content.

Back up the workspace metadata and DSH home to preserve Agent history.

## Deferred after alpha

- Tune target-specific MuPDF builds with representative PDF corpora before
  enabling optional LTO, PGO, allocator, or architecture-specific flags.
- Complete WYSIWYG round-tripping for tables, formulas, Mermaid, block IDs, and
  unknown extension nodes.
- Replace full-workspace text indexing with an incremental persistent index.
- Add Android/iOS adaptive shells and platform implementations.
