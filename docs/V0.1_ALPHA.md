# v0.1 alpha acceptance scope

This release is a usable vertical slice of the architecture in `软件架构.md`.
It deliberately proves the module boundaries and the main user journey before
implementing the full docking, native MuPDF, synchronization, and tool-running
agent subsystems.

## Required flows

1. First launch offers create/open workspace and does not create a blank note.
2. A workspace exposes the real directory tree and can open Markdown, text,
   image, and PDF documents in preview or pinned tabs.
3. Markdown can be edited, viewed as source, rendered for reading, formatted by
   shared commands, and atomically autosaved.
4. Search, outline, outgoing wiki links, tags, and backlinks navigate to files.
5. PDFs render inside the document area with page and zoom controls.
6. Agent chat streams from a configurable OpenAI-compatible endpoint, accepts
   current document context, can be cancelled, and persists its transcript.
7. Workspace, open documents, active tab, active tool, panel sizes, editor mode,
   and PDF page are restored after restart.
8. Empty, loading, permission, unsupported-file, and recoverable error states are
   shown at the point of failure.

## Architecture boundaries proven in alpha

- `commonMain`: document model, Markdown analysis, editor commands, and indexes.
- `desktopMain`: file system, persistence, PDF backend, HTTP provider, and UI.
- Files are content truth; `.xuexue` contains rebuildable state only.
- Toolbar and keyboard actions dispatch the same `EditorCommand` values.
- PDF and agent implementations sit behind service interfaces.

## Deferred after alpha

- Replace the alpha PDFBox backend with the specified MuPDF document actor,
  display-list worker pool, tile scheduler, GPU cache, overlays, and Range I/O.
- Arbitrary dock/float/tear-off windows and named layout presets.
- WYSIWYG block editing, tables, formulas, Mermaid, properties, block IDs, and
  unknown-syntax round-trip tests beyond source mode.
- File watching, rename transaction previews, reference rewriting, trash/undo,
  external-change merge UI, and full-text database indexing.
- Tool-calling agent loop, diff acceptance, trust policies, multiple providers,
  branching, compaction, skills, packages, and RPC mode.
- Android/iOS adaptive shells and platform implementations.
